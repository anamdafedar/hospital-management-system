# Hospital Management System (C Language)

---

## Project Overview

This is a simple **Hospital Management System** built using the **C programming language**.

It is a console-based application that manages patient records using file handling. The system allows users to add, view, search, update, and delete patient information.

---

## What I Learned From This Project

While building this project, I learned:

- File handling in C  
- Structures  
- Functions and modular programming  
- Strings and arrays  
- CRUD operations (Create, Read, Update, Delete)  
- Logical thinking and problem solving  

---

## Features

- Add new patient record  
- View all patient records  
- Search patient by ID  
- Update patient details  
- Delete patient record  
- File-based storage system (`patients.txt`)  
- Duplicate ID prevention  
- Simple console-based interface  

---

## How to Run

### 1. Compile the program

```bash
gcc hospital.c -o hospital
```

### 2. Run the program

#### Windows
```bash
hospital.exe
```

#### Linux / Mac
```bash
./hospital
```
